# Python Quiz Game

코데세이 E1-2 미션으로 제작한 Python 콘솔 기반 퀴즈 게임입니다.

## 1. 프로젝트 개요

Python 기본 문법과 객체 지향 프로그래밍을 활용하여 터미널에서 실행되는 객관식 퀴즈 게임을 개발했습니다.

사용자는 퀴즈 풀기, 새로운 퀴즈 추가, 퀴즈 목록 확인, 최고 점수 확인 기능을 사용할 수 있습니다. 퀴즈와 최고 점수는 JSON 파일에 저장되어 프로그램을 종료해도 유지됩니다.

## 2. 퀴즈 주제 및 선정 이유

- **주제:** Python 기초 문법
- **선정 이유:** Python 자료형, 조건문, 반복문, 함수 등 기초 개념을 퀴즈로 복습하고 학습 내용을 직접 확인하기 위해 선정했습니다.

## 3. 개발 환경

- 운영체제: Windows
- 개발 언어: Python 3.13
- 개발 도구: Visual Studio Code
- 터미널: PowerShell
- 버전 관리: Git / GitHub
- 외부 라이브러리: 없음 (Python 표준 라이브러리만 사용)

## 4. 실행 방법

Python 3.10 이상이 설치되어 있어야 합니다.

### 1) 저장소 복제

```bash
git clone https://github.com/hats0601-dev/E1-2.git
```

### 2) 프로젝트 폴더 이동

```bash
cd E1-2
```

### 3) 프로그램 실행

```bash
python main.py
```

실행 후 표시되는 메뉴에서 1~5번을 입력하여 기능을 사용할 수 있습니다.

## 5. 주요 기능

| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 퀴즈 풀기 | 등록된 4지선다 퀴즈를 풀고 점수를 확인합니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호를 입력하여 새 퀴즈를 등록합니다. |
| 3 | 퀴즈 목록 | 등록된 퀴즈의 개수와 문제 목록을 확인합니다. |
| 4 | 점수 확인 | 지금까지 기록한 최고 점수를 확인합니다. |
| 5 | 종료 | 데이터를 저장하고 프로그램을 종료합니다. |

### 추가 구현 사항

- 기본 Python 퀴즈 5개 제공
- 정답 및 오답 판정
- 정답률을 100점 만점으로 환산
- 최고 점수 갱신 및 유지
- 빈 입력, 문자 입력, 범위 밖 숫자 처리
- `Ctrl + C` 및 입력 종료 예외 처리
- JSON 파일 저장 및 불러오기
- 저장 파일이 없거나 손상된 경우 기본 퀴즈로 복구

## 6. 프로젝트 구조

```text
python-quiz-game/
├── main.py          # 프로그램 실행 진입점
├── quiz.py          # Quiz 클래스: 문제 및 정답 판정
├── quiz_game.py     # QuizGame 클래스: 전체 게임 진행
├── quiz_data.py     # 기본 퀴즈 데이터
├── storage.py       # JSON 저장 및 불러오기
├── state.json       # 퀴즈 목록과 최고 점수 저장
├── .gitignore       # Git 제외 파일 설정
└── README.md        # 프로젝트 설명 문서
```

### 클래스 구성

**Quiz**
- 문제와 선택지, 정답 번호 관리
- 문제 출력
- 사용자 정답 판정

**QuizGame**
- 퀴즈 목록과 최고 점수 관리
- 메뉴 출력 및 사용자 입력 처리
- 퀴즈 풀기, 추가, 목록, 점수 확인
- JSON 데이터 저장

## 7. 데이터 저장 형식

프로젝트 폴더의 `state.json`에 데이터를 UTF-8 JSON 형식으로 저장합니다.

```json
{
    "quizzes": [
        {
            "question": "Python에서 정수를 나타내는 자료형은?",
            "choices": ["str", "int", "bool", "list"],
            "answer": 2
        }
    ],
    "best_score": 80
}
```

- `quizzes`: 등록된 퀴즈 목록
- `question`: 문제 내용
- `choices`: 선택지 4개
- `answer`: 정답 번호 (1~4)
- `best_score`: 최고 점수 (0~100, 기록이 없으면 `null`)

파일이 없으면 기본 퀴즈 5개를 사용합니다. 파일 내용이 올바르지 않은 경우 오류를 안내하고 기본 데이터로 복구합니다.
