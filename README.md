# Python Quiz Game

코데세이 E1-2 미션으로 제작하는 Python 콘솔 퀴즈 게임입니다.

## 프로젝트 개요
Python 기본 문법과 객체 지향 프로그래밍을 활용하여
터미널에서 실행되는 퀴즈 게임을 개발합니다.

## 퀴즈 주제
Python 기초 문법

선정 이유: Python 기초 개념을 퀴즈로 복습하고,
프로그래밍 학습 내용을 직접 확인하기 위해 선택했습니다.

## 개발 환경
- Python 3.13
- Windows
- VSCode
- PowerShell
- Git / GitHub

## 주요 기능
- 퀴즈 풀기
- 퀴즈 추가
- 퀴즈 목록 확인
- 최고 점수 확인
- JSON 파일 저장 및 불러오기
