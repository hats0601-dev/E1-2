# Python Quiz Game

코데세이 E1-2 미션으로 제작한 Python 콘솔 기반 퀴즈 게임입니다.

## 1. 프로젝트 개요

사용자는 퀴즈 풀기, 퀴즈 추가·삭제, 퀴즈 목록 확인, 최고 점수 확인, 게임 기록 조회 기능을 사용할 수 있습니다. 문제는 무작위로 출제되며, 풀 문제 수를 직접 선택할 수 있습니다. 힌트 사용 시 해당 문제의 배점이 절반으로 줄어듭니다.

퀴즈 목록, 최고 점수, 게임 기록은 JSON 파일에 저장되어 프로그램을 종료해도 유지됩니다.

## 2. 퀴즈 주제 및 선정 이유

- **주제:** Python 기초 문법
- **선정 이유:** Python 자료형, 조건문, 반복문, 함수 등 기초 개념을 퀴즈로 복습하고 학습 내용을 직접 확인하기 위해 선정했습니다.

## 3. 개발 환경

- 운영체제: Windows
- 개발 언어: Python 3.13
- 개발 도구: Visual Studio Code
- 터미널: PowerShell
- 버전 관리: Git / GitHub
- 외부 라이브러리: 없음 (Python 표준 라이브러리만 사용)

## 4. 실행 방법

Python 3.10 이상이 설치되어 있어야 합니다.
실행 후 표시되는 메뉴에서 1~7번을 입력하여 기능을 사용할 수 있습니다.

### 1) 저장소 복제

```bash
git clone https://github.com/hats0601-dev/E1-2.git
```

### 2) 프로젝트 폴더 이동

```bash
cd E1-2
```

### 3) 프로그램 실행

```bash
python main.py
```

실행 후 표시되는 메뉴에서 1~5번을 입력하여 기능을 사용할 수 있습니다.

## 5. 주요 기능

| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 퀴즈 풀기 | 문제 수를 선택하고 무작위로 출제되는 퀴즈를 풉니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호, 힌트를 입력하여 등록합니다. |
| 3 | 퀴즈 목록 | 등록된 퀴즈의 개수와 문제 목록을 확인합니다. |
| 4 | 점수 확인 | 지금까지 기록한 최고 점수를 확인합니다. |
| 5 | 종료 | 데이터를 저장하고 프로그램을 종료합니다. |
| 6 | 퀴즈 삭제 | 퀴즈를 선택하고 확인 후 삭제합니다. |
| 7 | 점수 기록 조회 | 날짜, 문제 수, 정답 수, 점수를 확인합니다. |

### 추가 구현 사항

- 기본 Python 퀴즈 5개 제공
- 정답 및 오답 판정
- 정답률을 100점 만점으로 환산
- 최고 점수 갱신 및 유지
- 빈 입력, 문자 입력, 범위 밖 숫자 처리
- `Ctrl + C` 및 입력 종료 예외 처리
- JSON 파일 저장 및 불러오기
- 저장 파일이 없거나 손상된 경우 기본 퀴즈로 복구
- 퀴즈 출제 순서 무작위 변경
- 사용자가 풀 문제 수 선택
- 힌트 제공 및 힌트 사용 시 해당 문제 배점 50% 적용
- 퀴즈 삭제 전 확인 및 JSON 데이터 반영
- 게임별 날짜·시간, 문제 수, 정답 수, 점수 기록
- 저장된 게임 기록 조회

## 7. 데이터 저장 형식

프로젝트 폴더의 `state.json`에 데이터를 UTF-8 JSON 형식으로 저장합니다.

```json
{
    "quizzes": [
        {
            "question": "Python에서 정수를 나타내는 자료형은?",
            "choices": ["str", "int", "bool", "list"],
            "answer": 2,
            "hint": "숫자를 저장하는 자료형을 생각해 보세요."
        }
    ],
    "best_score": 100,
    "history": [
        {
            "datetime": "2026-11-03T17:46:06",
            "total_questions": 1,
            "correct_answers": 0,
            "score": 0
        }
    ]
}
```

- `quizzes`: 등록된 퀴즈 목록
- `question`: 문제 내용
- `choices`: 선택지 4개
- `answer`: 정답 번호 (1~4)
- `best_score`: 최고 점수 (0~100, 기록이 없으면 `null`)
- `hint`: 문제별 힌트 (생략 가능)
- `history`: 게임 플레이 기록 목록
- `datetime`: 게임을 완료한 날짜와 시간
- `total_questions`: 플레이한 문제 수
- `correct_answers`: 정답을 맞힌 문제 수
- `score`: 힌트 감점이 반영된 최종 점수 (0~100)

점수는 100점 만점으로 계산합니다. 힌트 없이 정답을 맞히면 해당 문제에서 1점, 힌트 사용 후 정답을 맞히면 0.5점을 획득하며, 총 획득 점수를 문제 수로 나누어 환산합니다.

파일이 없으면 기본 퀴즈 5개를 사용합니다. 파일 내용이 올바르지 않은 경우 오류를 안내하고 기본 데이터로 복구합니다.
